# 🌤️ Καιρός Αθήνας (Minimal Φθινοπωρινή Έκδοση)

Minimal web εφαρμογή καιρού αποκλειστικά για την Αθήνα, σχεδιασμένη σε ζεστούς φθινοπωρινούς τόνους.

## 📱 Χαρακτηριστικά
* **Τρέχουσες Συνθήκες:** Θερμοκρασία, υγρασία και ζωντανό εικονίδιο καιρού.
* **Ωριαία Πρόβλεψη:** Κατανομή θερμοκρασίας και καιρού έως τις 23:00.
* **Δυναμικές Προτάσεις Ντυσίματος:** Εξειδικευμένες προτάσεις ξεχωριστά για γυναίκες και άντρες με βάση την τρέχουσα θερμοκρασία και ώρα.
* **Πρόβλεψη Επόμενης Ημέρας:** Μέγιστη/ελάχιστη θερμοκρασία και περιγραφή για αύριο.
* **PWA & Mobile Ready:** Υποστήριξη εγκατάστασης στην αρχική οθόνη κινητών συσκευών με προσαρμοσμένο φθινοπωρινό εικονίδιο.
